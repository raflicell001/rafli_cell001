# DMRT 215 — Website Bengkel

Website statis responsive untuk DMRT 215. Bisa langsung dipakai di GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain responsive
- `script.js` — menu mobile + active navigation
- `assets/logo.png` — logo DMRT 215

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `dmrt215-bengkel`.
2. Upload semua file dan folder `assets`.
3. Masuk ke **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. Setelah proses deploy selesai, GitHub akan memberikan alamat website.
